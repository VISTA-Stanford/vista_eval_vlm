TL;DR

The VLM harness (vista_eval_vlm) already implements every experiment type end-to-end, so this is a stand-up + re-target, not new pipeline code. The work: provision a GPU VM in the BAA GCP project (the bench BQ dataset and CT/WSI buckets already live there — no cross-institution PHI sync, and 4–8B VLMs fit on one A100/H100, so B200s aren't needed), bump the harness from v1_3 to v1_5 — including the version-hardcoded path resolvers, not just two files — and materialize three modalities (EHR-timeline, CT NIfTI, pathology WSI). Frontier API models and the Weill B200s are deferred levers.
