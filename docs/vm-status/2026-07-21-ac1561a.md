## Step 0a — BQ schema-diff, `vista_bench_v1_5` vs `vista_bench_v1_6` (cheap, run first)

Resolves every distinct `task_source_csv` table from the live `valid_tasks.json` (VM-only file —
do not assume its contents), then diffs each table's column list between the two dataset versions.
Pathology-only tables (e.g. `diagnostic_tasks`) are *expected* to differ (additive/new columns);
anything used by a **non-pathology** task diverging is the actual signal to check.

```bash
cd src
python - <<'PY'
import json
from pathlib import Path
from google.cloud import bigquery

# paths.base_dir / paths.valid_tasks from configs/all_tasks.yaml
BASE_DIR = Path("/data/fries/users/rdcunha/vista_bench_cached/vista_bench")
VALID_TASKS = BASE_DIR / "tasks" / "valid_tasks.json"
PROJECT_ID = "som-nero-plevriti-deidbdf"  # already-de-identified project (query_utils.DEFAULT_BQ_PROJECT_ID)

valid_tasks = json.load(open(VALID_TASKS))
by_table = {}
for t in valid_tasks:
    by_table.setdefault(t["task_source_csv"], []).append(t["task_name"])

client = bigquery.Client(project=PROJECT_ID)

def cols(dataset, table):
    q = f"""
        SELECT column_name FROM `{PROJECT_ID}.{dataset}.INFORMATION_SCHEMA.COLUMNS`
        WHERE table_name = @table
    """
    job = client.query(
        q, job_config=bigquery.QueryJobConfig(
            query_parameters=[bigquery.ScalarQueryParameter("table", "STRING", table)]
        ),
    )
    return {r["column_name"] for r in job.result()}

print(f"{len(by_table)} distinct task_source_csv tables across {len(valid_tasks)} tasks\n")
for table, tasks in sorted(by_table.items()):
    v15 = cols("vista_bench_v1_5", table)
    v16 = cols("vista_bench_v1_6", table)
    removed = v15 - v16
    added = v16 - v15
    tag = "PATHOLOGY-TAGGED (differences expected)" if any(
        "path" in tn or tn in ("stage", "histologic_type", "pdl1_expression") for tn in tasks
    ) else "non-pathology"
    print(f"=== {table} [{tag}] — {len(tasks)} task(s): {sorted(tasks)[:3]}{'...' if len(tasks) > 3 else ''}")
    print(f"    removed/renamed (v1_5 only): {sorted(removed) or 'none'}")
    print(f"    added (v1_6 only):           {sorted(added) or 'none'}")
PY
```

**Expected:** for every table tagged `non-pathology`, `removed/renamed` is empty — no column
CT/EHR/text actually reads was dropped or renamed. Pathology-tagged tables may show additive
columns freely.
**STOP:** any `non-pathology` table shows a non-empty `removed/renamed` list — a breaking schema
change on a column CT/EHR/text reads. Report the table + column names here and do **not** proceed
to Step 0b.
