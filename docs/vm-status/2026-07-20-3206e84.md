## Step 2 — raw LOINC event-count check across the 20 already-banked persons

Reuses the existing 20-row `lumia_live_windowed` bank from the round-3 run
(`docs/vm-status/2026-07-20-a58f5f9.md`) — no new `golden_harness` run, no new person selection.
Bypasses `EHRAdapter`/`ehr_filters.py` entirely: `parse_lumia()` is the raw XML→DataFrame parse
step with zero filtering/dedup/windowing applied.

```bash
cd <repo-root>/vista_eval_vlm/src
python3 -c "
import pandas as pd
import meds_reader
import json

from context.adapters.ehr import parse_lumia, lumia_path_for
from vista_run.run_bq import TaskOrchestrator

MEDS_DB = '/home/rdcunha/vista_project/vista_bench/thoracic_cohort_meds/thoracic_cohort_meds_femr_db'
CORPUS_DIR = '/data/fries/datasets/vista_bench_ryan/thoracic_cohort_lumia'
LIVE_BANK = '<results_dir>/golden/.../progression_recurrence_free_survival_1_yr_no_image_lumia_live_windowed_golden.jsonl'

# Pull the 20 already-selected person_ids from the round-3 bank -- no new selection.
person_ids = []
with open(LIVE_BANK) as f:
    for line in f:
        rec = json.loads(line)
        person_ids.append(rec['person_id'])
assert len(person_ids) == 20, f'expected 20 rows, got {len(person_ids)}'

orch = TaskOrchestrator('<ABS_PATH_TO_configs/all_tasks.viewer.vm.yaml>', 'gemma3', 'google/medgemma-1.5-4b-it')
task_info = next(t for t in orch.valid_tasks if t['task_name'] == 'progression_recurrence_free_survival_1_yr')
df, timeline_col, source_csv = orch._load_task_data(task_info, use_no_report_csv=False, require_timeline=True)
embed_times = df.set_index('person_id')['embed_time'].to_dict()

database = meds_reader.SubjectDatabase(MEDS_DB)

legacy_counts, live_counts = [], []
for pid in person_ids:
    embed_time = pd.to_datetime(embed_times[pid])
    window_start = embed_time - pd.DateOffset(months=24)

    subj = database[pid]
    n_legacy = sum(
        1 for event in subj.events
        if str(event.code).startswith('LOINC/') and window_start <= pd.to_datetime(event.time) <= embed_time
    )
    legacy_counts.append(n_legacy)

    xml_path = lumia_path_for(pid, CORPUS_DIR)
    live_df = parse_lumia(xml_path)
    if live_df.empty:
        live_counts.append(0)
    else:
        mask = (
            live_df['code'].astype(str).str.startswith('LOINC/')
            & (live_df['time'] >= window_start) & (live_df['time'] <= embed_time)
        )
        live_counts.append(int(mask.sum()))

total_legacy = sum(legacy_counts)
total_live = sum(live_counts)
print(f'n_persons={len(person_ids)}')
print(f'total_legacy_raw_loinc={total_legacy}')
print(f'total_live_raw_loinc={total_live}')
print(f'raw_ratio={(total_live/total_legacy) if total_legacy else float(\"nan\"):.2f}')
print(f'per_person_legacy: min={min(legacy_counts)} median={sorted(legacy_counts)[len(legacy_counts)//2]} max={max(legacy_counts)}')
print(f'per_person_live: min={min(live_counts)} median={sorted(live_counts)[len(live_counts)//2]} max={max(live_counts)}')
"
```

**Expected:** prints the five aggregate lines above. Compare `raw_ratio` against the
already-observed rendered-line context (LOINC excess was 2724 lines across these same 20 rows) —
a similarly large raw-level gap is the confirmatory signal for the data-provenance hypothesis; a
raw ratio near 1.0 refutes it.
**Stop:** any exception (missing files, `KeyError` on `embed_time`/`person_id`, empty
`SubjectDatabase` lookup) — report the exception type/message only (no data payload), hand back to
the Mac; do not silently skip persons and report a partial aggregate as if it were complete.
**Destructive:** no — read-only queries against existing databases/files, no writes.
